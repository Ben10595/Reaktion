# Irgendwas-O-Mat

Eine kleine statische Website, die mehrere Mini-Funktionen bietet:

- zufällige Mini-Missionen generieren
- erledigte Aufgaben und Serien lokal zählen
- eine Browser-Notiz speichern
- Ja/Nein-Entscheidungen würfeln
- per Klick die Farbpalette wechseln

Öffne `index.html` direkt im Browser oder starte lokal einen kleinen Webserver:

```bash
python3 -m http.server 8000
```
